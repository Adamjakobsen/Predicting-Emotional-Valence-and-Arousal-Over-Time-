# Predicting Emotional Valence and Arousal Over Time

IN9550 home exam based on SemEval-2026 Task 2 Subtask 1: predict valence and arousal from diary entries, with longitudinal calibration using each user's history.

## Repository layout

```
datasets/          train.csv, test.csv 
eval/              official evaluation utilities 
artifacts/         generated artefacts (model outputs, metrics, submission CSVs)
results/           final submission CSVs for all paper models
figures/           plots generated by plot_results.py
lib.py             DeBERTa / Gemma LoRA training library
longitudinal_utils.py  feature engineering, Ridge calibration, metrics
main.py            full experiment runner 
transformer_worker.py  single-run worker launched per fold/seed by main.py
plot_results.py    generate all paper figures
ablation_features.py   incremental feature-group ablation 
```

## Setup

```bash
pip install -r requirements.txt
```

A CUDA-capable GPU or MPS is required for DeBERTa and Gemma training.


## Running the full paper pipeline

```bash
python main.py \
  --train datasets/train.csv \
  --test  datasets/test.csv \
  --artifacts_dir artifacts/paper_results \
  --cache_dir     artifacts/cache \
  --models tfidf_ridge deberta_base deberta_base_ccc deberta_base_mean_pool \
           deberta_large gemma_lora \
  --seeds 13 17 23 \
  --n_splits 3
```

Or use the convenience script (runs the default model set):

```bash
bash run_all_paper_results.sh
```

Outputs per model are written to `artifacts/paper_results/<model>/`:

| File | Description |
|---|---|
| `metrics.json` | validation + test metrics for all variants |
| `text_predictions.npz` | OOF train predictions + test predictions |
| `submission_longitudinal_default.csv` | primary submission file |
| `submission_longitudinal_no_text.csv` | history-only ablation |
| `submission_longitudinal_no_history.csv` | text-only ablation |

The final submission CSVs for all paper models are also collected in `results/`.

## Evaluating a submission file

From /eval run:
```bash
python python eval_interface.py --task subtask1 --submission ../final_submission.csv --labels ../datasets/test.csv --dimension arousal
```




## Reproducing individual figures

```bash
python plot_results.py
```

Saves four PNG files to `figures/`:

| File | Paper figure |
|---|---|
| `fig2_loss_curves.png` | Figure 2 — training loss curves |
| `fig3_main_results.png` | Figure 3 — main results bar chart |
| `fig4_feature_weights.png` | Figure 4 — Ridge feature weights |
| `fig5_ablation.png` | Figure 5 — loss / pooling ablation |

## Feature ablation analysis

```bash
python ablation_features.py
```

Prints an incremental table showing the contribution of each feature group
to `r_composite` on the test set (uses cached DeBERTa-base predictions.
no retraining needed).
